# Shopping List+

A Flutter shopping list app with advanced features.

## Features

- Add and delete items
- Mark items as bought
- Track quantities with +/- buttons
- Prevent duplicates (increments quantity instead)
- Undo delete with SnackBar
- Filter by: All, To buy, Bought
- Item details: name, note, and category (Food/Drinks/Home)

## Getting Started

```bash
flutter pub get
flutter run
```
